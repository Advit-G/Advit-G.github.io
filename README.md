# Advit Gangwal — Finance & Data Analytics Portfolio

A responsive, single-page personal portfolio built for the GitHub Pages assignment. It includes the required one-sentence professional statement, skills showcase, and three project/experience summaries.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named `advitg.github.io` (or another repository name if your instructor permits it).
2. Upload `index.html`, `styles.css`, and this README to the repository's root folder.
3. In GitHub, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then click **Save**.
4. Wait for the Pages deployment to finish. The site URL will be `https://advitg.github.io/` for the username-matching repository, or shown in **Settings → Pages** for another repository.
5. Confirm the repository is public and test the live URL before submitting both links.

## Personalize before publishing

- Verify the LinkedIn link in `index.html` points to your public profile.
- Confirm every project metric is current and approved for public use.
- Add links to public examples if you have them. Client tax records and private campaign dashboards should stay private.

The design uses Google Fonts when online and system fallbacks when offline. No JavaScript or build tools are required.
